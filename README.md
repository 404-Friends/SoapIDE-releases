# SoapIDE

**One window for your tasks, your git repos and your AI coding agents.** Built by [404Friends](https://404friends.ge) for Windows.

## ⬇ Download

**[Download SoapIDE for Windows (SoapIDE-Setup.exe)](https://github.com/404-Friends/SoapIDE-releases/releases/latest/download/SoapIDE-Setup.exe)**

This link always gives the newest version. Run it and SoapIDE installs for your user, with no admin needed, then keeps itself up to date.

> The builds aren't code-signed yet. If Windows says *"Windows protected your PC"*, click **More info → Run anyway**.

## What it does
- **Tasks:** a Kanban board per client/project, with optional ClickUp/Jira import. "Start work" creates a branch or worktree and launches Claude Code or Codex already briefed on the task.
- **Repos:** branches, diffs, staging, commits (with a secret scan), stashes, worktrees, and review of what an agent changed. It replaces the IDE's git panel.
- **Agent terminals:** they tell you when an agent is working, needs your permission, or has finished.
- **Reports:** a worklog, timesheets, AI usage per client, and PDF progress reports for clients.
- **System:** what's eating your RAM, local services (databases…) and who's holding which port.

**Needs:** Windows 10/11 x64 and [Git for Windows](https://git-scm.com/download/win). **Optional:** [Claude Code](https://docs.claude.com/en/docs/claude-code), the Codex CLI, and [nvm-windows](https://github.com/coreybutler/nvm-windows).

All versions and release notes: [Releases](https://github.com/404-Friends/SoapIDE-releases/releases). `SoapIDE-portable.exe` runs without installing but doesn't auto-update.

This repository holds binaries only; the source is private.
