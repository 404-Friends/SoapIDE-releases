# SoapIDE releases

Installers and the auto-update feed for **SoapIDE**, 404Friends' daily dev cockpit: tasks, repos, branches and Claude Code / Codex agent terminals in one Windows app.

**Download:** grab `SoapIDE-Setup-x.y.z.exe` from the [latest release](https://github.com/404-Friends/SoapIDE-releases/releases/latest). It installs per-user, no admin needed. The installed app updates itself from this page.

`SoapIDE-x.y.z-portable.exe` runs without installing, but can't auto-update.

The builds aren't code-signed yet. If Windows SmartScreen warns you, choose *More info → Run anyway*.

This repository holds binaries only. The source is private.
